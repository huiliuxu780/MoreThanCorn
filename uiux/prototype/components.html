1 · ResourceCard 解剖
统一卡片组件，结构固定：Icon + Status / Name / Description / Metadata / Usage。六类资源共用，仅图标、副标题与元数据字段随类型变化。高度自适应（最小 168px），网格 1/2/3/4 列响应式。

2 · ResourceStatusBadge 状态体系
生命周期（所有类型）与健康度（来自测试/巡检）正交。颜色仅为辅助语义，文字始终存在（沿用现有 StatusBadge 原则）。
Enabled Disabled Healthy Degraded Error Draft Ready Deprecated
状态维度含义Badge
Enabled生命周期可被 Workflow 节点 / 下游对象选择使用success
Disabled生命周期停用：保留数据与引用，禁止新引用neutral
Healthy / Degraded / Error健康度最近一次 Test 或巡检结果；测试失败不自动停用success warning danger
Draft / Ready / DeprecatedData Asset Lifecycle沿用现有 data-assets 语义info success neutral
3 · 空态 / 筛选空态 / 加载骨架
与现有 EmptyState、FilteredEmptyState、CardGridSkeleton 保持一致。
暂无 MCP Server
创建第一个 MCP Server，为 Agent 接入外部工具
没有匹配的资源
尝试调整关键词或清除筛选条件
4 · ResourceActionMenu 操作菜单
卡片 hover 出现 ⋯ 触发；详情页 Header 使用同款菜单。删除始终位于底部危险区。
菜单项行为
查看详情进入 ResourceDetailLayout 页面
编辑打开类型表单（Dialog 或编辑页，随类型）；有版本类型产生新草稿版本
测试打开 ResourceTestDialog，即时执行
停用 / 启用切换生命周期状态；停用后不可被新节点选择，已有引用保留
删除有引用 → 拦截对话框并列出引用方；无引用 → 二次确认。使用中永不物理删除

6 · 删除防护（使用中的 Resource 不允许删除）
判定口径：AI Resources 看 Workflow Version Node Config 引用；Data Resources 看下游 Data Asset / Data Definition 链路。
无法删除「工单系统查询」
该资源正被 3 个 Workflow Version 引用：客诉归因 v4 / 质检复核 v7 / 专家研判 v2。
删除「短信通知」？
无引用。删除后配置与版本历史不可恢复。
7 · Create Resource Wizard 与类型表单清单
四步固定骨架；第二步随类型切换强类型表单；第三步必须测试通过方可保存（见 wizard.html 可交互演示）。
类型表单关键字段测试方式版本
Model名称 / Provider / Model Key / 能力标签 / 描述最小补全请求Model Version
Tool名称 / 类型（builtin/http）/ 请求配方 spec / 描述样例入参执行ToolVersion
MCP Server名称 / Transport / 命令或 Endpoint / 环境变量 / 描述握手 + 工具发现—
Knowledge Source名称 / 类型（向量/文档）/ Embedding 模型 / 内容来源 / 描述样例检索—
Datasource名称 / 类型 / 连接地址 / 凭证 / 描述连通性检查—（变更记录）
Data Asset名称 / 所属 Datasource / 表路径 / 一条数据代表什么 / 时间字段抽样读取—（变更记录）
