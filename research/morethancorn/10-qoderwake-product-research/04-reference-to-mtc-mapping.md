## 0. 前置硬事实（约束所有行）

1. **版本双轨（A1，03 §1.1/§1.3/§1.5）**：本项目实装并 pin `agentscope==2.0.7`（PyPI registry wheel）；"2.0.8"仅存在于官方 main@ff8697ec（未发布：PyPI 404、无 tag；PyPI 最新 2.0.7.post1）。2.0.7 中无任何 pipeline 代码（03 §1.1 P10/P11）。凡依赖 pipeline 官方对象的结论均受发布闸门约束（05 建议 OD-16）。
2. **官方 pipeline 契约面极小且零治理（A1，03 项1/项2/项4/项10、§3.2/§4.2）**：GoalPipeline=单 executor+verifier 循环、状态纯内存（`_iters`/`_goal`）、`max_retries`/`verifier_reset_context` 为 dead params；未接入 create_app；多 stage/并行/barrier/选择性重做/版本化/持久化/服务层托管全部列"平台必须补齐"。官方持久化保证仅到 Agent 会话级（SessionRecord.state: AgentState、SessionStatus 四态、HITL 靠 reply_id 路由，03 项5/项8）。
3. **官方 app 服务层与我方 server 职责重叠（A1，03 §4.3/§4.4）**：2.0.7 自带 SQL/Redis 存储、分布式 session 锁、ChatService、cron（调度器有单点约束）、IM 网关、权限/预算 middleware——哪些启用、哪些由我方替代是未决取舍（05 建议 OD-15）。
4. **我方运行环境级断链（C1，02 §0.2/§0.3/§1 Q5）**：8301–8303 三个 Provider 全部不可达；DB 全部 active Release 绑定已退役 Provider（openai-agents 源码从未入 git、DSH 已归档）；AgentScope Provider health=error 且零 Release 绑定。当前不存在任何"发布→可运行"的活链路——所有 ADAPT/ADOPT 结论均以修复此断链为共同前置（05 §3 P0 前置清单）。
5. **既有拍板（不得违背，07 v1 头部+任务书 §1.1/§8）**：AgentScope 为唯一运行时底层；市场制不照搬；IM 渠道不抄；CoT 不外露；无 schema 稳定性承诺（A1，03 项12：46 commits/174 文件跨版本漂移）⇒ 一切 AgentScope 事件/状态入我方事实层必须经版本冻结的映射。
6. **任务三义（任务书 §1.3，O 级实证见 01 QW-02/QW-04/QW-07）**：平台任务=看板投影行（run/session 级）；自动任务=AutomationDefinition 定义；Agent 内部计划项=AgentScope Task 工具。三者不得合并成同一张 Task 表（落地见本表行 3/4/14 与 05 §5）。
