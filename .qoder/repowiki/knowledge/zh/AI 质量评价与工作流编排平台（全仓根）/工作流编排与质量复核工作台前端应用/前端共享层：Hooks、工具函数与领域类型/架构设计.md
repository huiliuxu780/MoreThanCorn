模块按职责划分为三个并列子目录，依赖方向单向：hooks → lib + domain/types；lib 不反向依赖 hooks；domain/types 零运行时依赖。
- `src/domain/types.ts`：全局类型源头，集中定义 ListParams/ListResponse<T> 分页契约、QualityResult（含 CriterionResult/TranscriptSegment/BusinessFact）、EvaluationAgent（含 AgentNodeDef/AgentEdgeDef 图）、Tool/ToolDetail、DataAsset/DataAssetField、AnalysisTask/Run/InteractionExecution、ResultRuleSet、Connection 等实体，作为 services/ 与 UI 层共同遵守的前后端契约。
- `src/hooks/`：纯 React Hook 集合。`use-async-data.ts` 封装 Loading/Error/Retry 统一态并支持重试；`use-list-query.ts` 以 URL search params 为唯一事实来源，通过 react-router-dom 的 useSearchParams 同步读写 search/page/pageSize/sort/filters/tab，并在关键参数变化时自动重置到第一页；`use-mobile.ts` 基于 matchMedia 暴露响应式 isMobile 布尔值。
- `src/lib/`：无副作用工具函数。`list-filters.ts` 实现 key:value,key2:value2 格式的 filters 编解码；`time.ts` 基于 date-fns 提供 UTC 存储与企业时区展示及多种时长格式化；`utils.ts` 通过 clsx + tailwind-merge 暴露 cn() 供 shadcn/ui 组件使用。
