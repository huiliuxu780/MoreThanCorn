- 列表查询参数统一通过 ListParams 接口并以 URL search params 为单一事实来源，由 useListQuery 同步读写，search/filters/sort/tab 变化时自动重置到第一页。
- 所有业务实体状态使用字符串字面量联合类型（如 Draft|Testing|Published|Deprecated、SUCCESS|ERROR|SKIPPED、PASS|FAIL|N/A），禁止硬编码魔法字符串。
- 时间值统一以 ISO UTC 字符串存储，展示时通过 time.ts 中的格式化函数转换为企业时区可读形式。
- filters 查询串采用 key:value,key2:value2 的紧凑格式，并通过 parseListFilters / serializeListFilters 成对编解码。
- 颜色与状态语义通过 StatusTone token 表达，组件层禁止直接书写 hex 色值。
- Hook 返回对象结构保持一致：异步数据类返回 { data, loading, error } 并附带 retry 方法，便于调用方统一渲染。
