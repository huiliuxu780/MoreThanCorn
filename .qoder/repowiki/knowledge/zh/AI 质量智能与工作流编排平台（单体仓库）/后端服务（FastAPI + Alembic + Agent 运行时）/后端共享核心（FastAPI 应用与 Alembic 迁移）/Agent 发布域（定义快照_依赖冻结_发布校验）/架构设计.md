模块为独立的领域层文件 `server/app/agent_release.py`，不暴露 HTTP 接口，仅被上层 router/service 调用。
- 职责分层：`build_definition` / `build_common_config` 负责按 Agent 类型（autonomous vs dialogue/expert-group）生成 definition 与 CommonAgentConfig 快照；`freeze_dependencies` 通过 `_resolve_tool/_resolve_workflow/_resolve_knowledge` 将运行时引用解析为确定版本并标记 FROZEN/MISSING/DISABLED/UNPUBLISHED；`artifact_hash` 对 definition+common+dependencies 三要素做 SHA-256 哈希；`validate_publish` 集中执行业务规则（名称长度、prompt/model/graph/members/memory）；`next_version_no` 提供版本号递增。
- 依赖方向单向向外：仅依赖 `models`（ORM）、`schemas.WorkflowDefinition`（Pydantic 图定义）、`validator.validate`（工作流图校验），不反向依赖路由或业务编排层。
- 数据隔离：definition 快照使用 `json.loads(json.dumps(wf.draft_definition))` 深拷贝草稿图，确保发布后编辑草稿不影响已发布版本；依赖冻结结果以结构化 dict 返回，供持久化到 AgentVersion。
