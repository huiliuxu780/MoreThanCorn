本模块由四个同级 React 页面组成，按业务对象分为两层：
- 资产层：`data-assets.tsx` 通过 `useListQuery` + `useAsyncData` 加载资产列表，支持 lifecycle/health 过滤与分页；`data-asset-editor.tsx` 负责单条资产的 Draft→Ready 编辑流程，内含 Schema 表格、Eligibility 规则、Validate Sheet 与 Revision History Sheet。
- 定义层：`data-definitions.tsx` 列出属于某 Data Asset 的 Definition 并支持创建；`data-definition-editor.tsx` 维护 fieldSchema 与 eligibility，调用 `defApi.infer` 从 Data Asset 推断字段后保存或发布。
依赖方向单向向下：页面 → `@/services/mock-service` / `@/services/resource-api` / `@/services/wf-api` → 后端 routers；状态展示统一使用 `StatusBadge`、`TableFrame`、`EmptyState`、`Pagination` 等共享 UI 组件；权限通过 `rbac.can('asset.manage')` 控制编辑态。版本管理在资产侧体现为 revision 递增与 Draft/Ready/Deprecated 生命周期，在定义侧体现为 `revision` + `publish` 动作。
