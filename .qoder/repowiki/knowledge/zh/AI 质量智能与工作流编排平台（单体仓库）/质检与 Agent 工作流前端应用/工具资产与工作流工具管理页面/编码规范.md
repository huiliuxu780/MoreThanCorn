- 列表页统一采用 `useListQuery(pageSize)` + `useAsyncData(api, deps)` 组合，并通过 `parseListFilters`/`serializeListFilters` 在 URL 查询参数中持久化 filters/search/sort/page。
- 页面骨架固定为 `PageContainer` + `PageHeader`（含 title/description/actions）+ 内容区 + `Pagination`，错误/加载/空态分别用 `ErrorState`、`CardGridSkeleton`、`EmptyState`/`FilteredEmptyState` 呈现。
- 权限控制通过 `rbac.can('tool.manage')` 判断后再渲染操作按钮（如创建、Publish），避免在组件内硬编码业务逻辑分支。
- 表单字段统一使用 `FormField` 包裹 `Input`/`Select`/`Textarea`，配合 `SectionHeader` 分组展示，保持视觉与交互一致性。
- 复杂交互（Test、Publish、Version History）以 `Sheet` 或 `Dialog` 弹窗形式承载，而非跳转新路由，维持单页编辑体验。
- 状态与版本语义严格对齐领域模型：Tool 使用 `governance`（Enabled/Disabled/Deprecated）与 `versionStatus`（Draft/Published），并在 UI 上通过 `StatusBadge` 与 `currentVersion`/`versions[]` 展示。
