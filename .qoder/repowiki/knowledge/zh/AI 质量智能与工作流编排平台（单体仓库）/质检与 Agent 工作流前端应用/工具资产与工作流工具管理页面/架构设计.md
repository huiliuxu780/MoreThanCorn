本模块由三个并列的 React 页面组成，分别承担不同职责：
- `tools.tsx`：基于 mock-service 的 Tool 列表页，使用 `useListQuery` + `useAsyncData` 组合实现分页、搜索、按 capability/governance 过滤与排序，并以 4 列紧凑卡片网格展示 Tool 元信息（名称、capability badge、governance 状态、版本号），通过 RBAC (`rbac.can('tool.manage')`) 控制“创建 Tool”入口。
- `tool-editor.tsx`：单页式 Tool 编辑器，支持新建与编辑两种模式（`isCreate = !toolId || toolId === 'new'`），内部以多个 `<section>` 分块组织基本信息、HTTP 请求（Connection/Method/Path/Body）、Input Contract（字段名/类型/Required/Location/RequestKey 表格）、Output Contract、治理开关；通过 Sheet 承载 Test 面板，Dialog 承载 Publish 对话框（含配置完整性校验链），并另开 Sheet 展示 Version History。数据源为 `getTool`，连接池来自 `mocks/data.connections`。
- `wf-tools.tsx`：面向工作流后端的轻量 Tool 管理页，直接调用 `services/wf-api` 的 `pagedApi.tools` 及自定义 `api()` 封装对 `/api/tools` 的 CRUD 与 `/api/tools/:id/test` 测试，独立维护本地 state 而非共享 hooks。

依赖方向单向向外：页面 → `@/hooks/use-*` / `@/components/app/*` / `@/components/ui/*` / `@/services/*`，不反向引用其他页面；版本与状态语义遵循项目约定（Draft/Published、Enabled/Disabled/Deprecated、versionNote/publishedAt）。
