模块按职责划分为三层：
- `src/components/ui/`：纯展示型原子组件（button、table、dialog、sidebar、sonner 等），全部基于 shadcn/ui + Radix UI primitives，通过 class-variance-authority 管理 variant/size 变体，依赖 `@/lib/utils` 的 `cn` 合并 className，不持有业务状态。
- `src/components/app/`：应用级布局与通用业务容器。`app-shell.tsx` 作为根 Shell，组合左侧窄轨导航（`AppRail`）、顶部 sticky Header（含面包屑）、`Outlet` 内容区与 Toaster；`app-sidebar.tsx` 通过声明式 `NAV_GROUPS` 数组驱动可折叠子菜单，并以 `rbac.can(permission)` 做权限裁剪；`page.tsx` 提供 `PageContainer`、`Breadcrumbs`、`PageHeader`、`SectionHeader` 统一页面骨架；`table-frame.tsx`、`pagination.tsx`、`status-badge.tsx`、`status-indicator.tsx`、`form-field.tsx`、`filters.tsx`、`list-state.tsx` 封装表格、分页、状态标签、表单字段、筛选器与列表状态等跨页面复用能力。
- `src/config/`：全局只读配置。`ui-terms.ts` 集中产品名、导航文案、`STATUS_LABELS` 与 `STATUS_TONES`（将后端枚举映射到 `StatusTone` 语义 token），禁止硬编码 hex；`enterprise.ts` 暴露企业时区与 locale。
依赖方向单向：`app/*` → `ui/*` → `config/*` → `domain/types`，业务页面仅消费本模块导出的布局与组件，不反向引用。
