本模块为纯脚本集合，按用途分为两类：
- CDP 工具库 `cdplib.py`：基于 `websockets` 封装 Tab/Network/Runtime/Page 能力，提供 `open`/`attach`/`eval`/`click`/`shot`/`api` 等异步方法，并支持拦截 `Fetch.requestPaused` 以控制请求成败。
- Node.js E2E 脚本（`.mjs`）：全部通过 HTTP 调用本地 `http://127.0.0.1:9222` 的 Chrome 调试端口创建或附加标签页，再经 WebSocket 发送 CDP 指令驱动 `localhost:5173` 前端；每个脚本自包含 `send`/`ev`/`click`/`type`/`drag`/`shot` 等辅助函数，并以固定截图路径（`/tmp/qACC-*`、`/tmp/qR-*`、`/tmp/qE2E-*`）输出验收证据。
- `e2e-replica.mjs` / `e2e-replica2.mjs` 针对 UI 复刻规范（# 级联、palette 外点关闭、发布模态图标等）进行用例化断言；`e2e-p0.mjs` 覆盖 create→add node→connect→configure→autosave→reload→checklist 主流程；`e2e-acceptance.mjs` 做最小 acceptance 检查。
- `verify-fullstack.mjs` 不依赖浏览器，直接调用后端 `http://127.0.0.1:8100` 的 REST API，按 S1–S14 阶段串联 Connection/Datasource/Data Asset/Data Definition/AI Resources/Workflow Run/Rule Engine/Review/Task/Batch/Schedule/Delete-protection/Evaluation/Agent run/version pinning 等场景，使用 `pollRun`/`pollAgentRun` 轮询终态并以 PASS/FAIL 汇总退出码。
依赖方向单向：脚本 → CDP/HTTP → 前端或后端服务，模块之间无相互引用。
