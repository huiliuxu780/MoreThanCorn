### AI Quality Intelligence Platform
- 定义：企业智能质量平台（简称 AI 质检平台），面向企业内部使用的 AI 驱动质量评价与业务洞察系统，V1 聚焦智能质检 → 坐席质检场景。
- 别名：质量平台、质检平台、AI 质检

### 冻结基线文档
- 定义：位于 `初始化doc/` 的四份基线文档集合，包括产品架构冻结文档（Master）、Design Spec、Implementation Spec 与 Codex Handoff，用于统一产品对象语义、页面交互、路由状态与实现细节的优先级冲突处理规则。
- 别名：基线文档、Master、Design Spec、Implementation Spec、Handoff

### SDD
- 定义：System Design Document，位于 `docs/sdd/`，按阶段（phase a~d）拆分的系统设计文档，涵盖正确性清理、Agent 聚合发布、可观测性与节点系统、产品面与治理等演进路线。
- 别名：系统设计文档、Phase A/B/C/D

### Agent 工作流
- 定义：由多个节点（LLM、分类器、代码、插件等）组成的有向图式执行流程，通过 `WorkflowDefinition` 描述并在后端 runner 中调度执行，前端通过 @xyflow/react 可视化编辑。
- 别名：工作流、workflow、节点图

### Connection
- 定义：对外部服务（如 LLM 提供商、知识库源）的连接凭证抽象，包含鉴权信息、端点等，被 Agent/Runner 在执行时解密并注入调用上下文。
- 别名：连接、连接凭证、KnowledgeSource

### Run / NodeRun / RunEvent
- 定义：一次工作流执行的记录实体：`Run` 表示顶层执行，`NodeRun` 表示单个节点执行，`RunEvent` 记录执行过程中的事件日志，三者构成执行追踪与可观测性的核心数据模型。
- 别名：执行记录、节点执行、运行事件

### 质量总览 / 质量结果 / 坐席分析
- 定义：智能质检域的三大核心页面：质量总览提供全局指标看板，质量结果展示质检判定明细，坐席分析针对单坐席维度下钻分析。
- 别名：质检三页、智能质检域

### 任务（Task）
- 定义：配置管理域中的质检任务实体，关联 Agent、数据源、评估样本等，支持 Wizard 创建与编辑表单复用。
- 别名：质检任务、Task

### Result Rule（结果规则）
- 定义：定义质量判定逻辑的规则配置，用于对运行结果进行评分、分类或标记，属于配置管理域的重要资产。
- 别名：结果规则、Rule

### Data Asset / Data Definition
- 定义：数据资产与数据定义两个相关但独立的配置项：前者描述可用数据源，后者描述数据结构与字段映射，共同支撑质检任务的输入配置。
- 别名：数据资产、数据定义、Data Source

### RBAC
- 定义：基于角色的访问控制，在前端通过 `services/rbac.ts` 实现权限判断，影响页面入口与操作按钮的可见性。
- 别名：角色权限、权限控制

### StatusTone
- 定义：UI 状态语义 token，集中定义在各页面中显示的状态标签（如运行状态、质量等级）对应的视觉色调，避免分散的颜色魔法值。
- 别名：状态色、状态 Token
