- HTTP 路由按业务域拆分到 app/routers/*.py，并在 main.py 中集中 include_router 注册。
- 数据库连接与 Session 通过 app/db.py 单例提供，ORM 模型集中在 app/models.py 并由 Alembic 版本化管理。
- 敏感配置（数据库 URL、API Token）一律通过环境变量注入，不在代码中硬编码。
- 版本管理贯穿多个实体（Agent、Tool、DataAsset、ResultRuleSet），统一包含 publishedAt/publishedBy/versionNote 字段。
- 执行状态（Run/InteractionExecution）与质量结果（QualityResult/CriterionResult）严格分离，前者记录 SUCCESS/ERROR/SKIPPED，后者记录 PASS/FAIL/N-A 及 severity/confidence。
