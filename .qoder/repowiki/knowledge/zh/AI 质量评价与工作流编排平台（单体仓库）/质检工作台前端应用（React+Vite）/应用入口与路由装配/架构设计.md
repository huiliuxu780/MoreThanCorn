模块由四个文件构成应用启动链：`src/main.tsx` 作为 Vite 入口，使用 `react-dom/client` 的 `createRoot` 在 `#root` 节点渲染，包裹 `StrictMode` + `BrowserRouter` + `TooltipProvider`（来自 `@/components/ui/tooltip`）后挂载 `<App />`；`src/app.tsx` 通过 `React.lazy` + `Suspense` 对 pages 目录下的各功能页进行按需加载，并以 `Routes` 集中声明路由表，统一嵌套在 `AppShell`（sidebar-03 模式）之下，按领域划分为智能质检（/quality/*）、配置管理（/config/tasks|agents|workflows|ai-resources|data-resources|data-assets|result-rules）、系统设置（/settings/*）及 403/404 兜底，并提供旧 `/config/tools` → `/config/ai-resources` 的重定向；`src/index.css` 基于 Tailwind v4 的 `@import "tailwindcss"` 引入，定义 oklch 色板变量并在 `:root` / `.dark` 双主题下映射到 shadcn 语义 token（background/foreground/card/primary/secondary/muted/accent/destructive/sidebar/chart-*），通过 `@theme inline` 暴露为 CSS 变量供组件消费；`src/vite-env.d.ts` 仅引用 `vite/client` 以启用 Vite 内置类型增强。依赖方向单向：main → app → components/pages/services，不反向引用业务逻辑。
