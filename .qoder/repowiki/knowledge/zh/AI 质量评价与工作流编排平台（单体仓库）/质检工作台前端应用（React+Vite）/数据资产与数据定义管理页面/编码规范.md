- 列表页统一采用 FilterBar + SearchField + Select 过滤 + TableFrame/Table/Pagination 的组合结构，并通过 `parseListFilters`/`serializeListFilters` 将筛选条件同步到 URL query。
- 数据获取统一封装在 `useAsyncData` 中，以 params（search/page/pageSize/filters）作为依赖数组，错误时渲染 `ErrorState`，加载中渲染 `TableSkeleton`，空数据区分有过滤条件的 `FilteredEmptyState` 与无数据的 `EmptyState`。
- 编辑页通过 `isDraft = isCreate || asset?.lifecycle === 'Draft'` 与 `rbac.can('asset.manage')` 组合计算 `readOnly`，并以 `<fieldset disabled={readOnly}>` 包裹表单区域实现统一的只读态。
- 生命周期与状态使用 `StatusBadge` 展示，健康度异常通过 `StatusNotice tone='danger'|'warning'` 呈现，禁止硬编码颜色。
- 复杂操作（Validate、Revision History）以 shadcn `Sheet` 抽屉承载，而非跳转新页面，保持编辑上下文不丢失。
- 字段类型枚举集中声明（如 `FIELD_TYPES = ['String','Number','Boolean','DateTime','Object','Array']`），并在多处 Select 中复用，避免散落的字符串字面量。
