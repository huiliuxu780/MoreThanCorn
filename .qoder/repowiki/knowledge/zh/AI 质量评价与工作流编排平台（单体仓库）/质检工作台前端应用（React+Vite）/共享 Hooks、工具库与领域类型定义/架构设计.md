本模块按职责划分为三个并列子目录，均无内部依赖：
- `src/hooks/`：纯 React Hook，封装跨页面复用的交互逻辑。`use-async-data.ts` 提供 Loading/Error/Retry 统一态；`use-list-query.ts` 以 URL search params 为唯一事实来源实现分页、排序、筛选与 tab 切换，并自动在关键参数变化时重置到第一页；`use-mobile.ts` 基于 `matchMedia` 暴露响应式断点。
- `src/lib/`：无副作用的工具函数集合。`list-filters.ts` 实现 `key:value,key2:value2` 格式的 filters 编解码；`time.ts` 基于 `date-fns` 提供 UTC 存储、企业时区展示及多种时长格式化；`utils.ts` 通过 `clsx` + `tailwind-merge` 暴露 `cn()` 供 shadcn/ui 组件使用。
- `src/domain/types.ts`：全局类型源头，集中定义 ListParams/ListResponse、QualityResult（含 CriterionResult、TranscriptSegment、BusinessFact）、EvaluationAgent/AgentNodeDef、Tool/DataAsset/AnalysisTask/Run/InteractionExecution/ResultRuleSet/Connection 等实体，作为 services/ 与 UI 层共同遵守的前后端契约。
依赖方向单向：hooks 仅依赖 lib 和 domain/types；lib 不反向依赖 hooks；domain/types 零运行时依赖，可被任意层引用。
