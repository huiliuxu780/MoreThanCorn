- 所有用户可见文案（产品名称、导航项、状态中文）集中在 `config/ui-terms.ts`，组件中通过 `UI_TERMS.*` 引用，禁止在页面内硬编码字符串。
- 状态显示统一通过 `STATUS_LABELS` 获取中文文案、`STATUS_TONES` 映射到 `StatusTone` 语义 token，再由 `status-badge` / `status-indicator` 渲染，禁止在业务组件内硬编码颜色或状态文本。
- 原子 UI 组件采用 cva + Slot 模式：用 `cva` 定义 variant/size 变体，以 `data-variant` / `data-size` 属性标记 DOM，并通过 `cn()` 合并外部 className。
- 导航入口以声明式 `NAV_GROUPS` 数组描述（label/to/icon/permission），由 `AppSidebar` 与 `AppRail` 共同消费，新增一级入口需修改该数组而非复制渲染逻辑。
- Shell 内工作区级路由（如 `/quality/results/:id`、`/config/agents/:id`）通过正则白名单判断并隐藏面包屑，非工作区路由统一走 `useRouteBreadcrumbs` 推导层级。
- 页面容器统一使用 `PageContainer`（支持 `wide` 切换最大宽度）、`PageHeader`、`SectionHeader` 组合标题/描述/状态/操作区，避免各页面自行拼装头部结构。
