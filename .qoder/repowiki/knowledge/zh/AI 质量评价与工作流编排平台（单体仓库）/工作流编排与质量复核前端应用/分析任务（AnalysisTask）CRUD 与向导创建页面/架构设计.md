模块以 React Router 页面组件为入口：`tasks.tsx` 负责任务列表（分页、搜索、按 status/agent/dataAsset 过滤），通过 `useListQuery` + `parseListFilters/serializeListFilters` 将 URL 查询参数持久化；`task-detail.tsx` 展示单个任务的配置快照与 Run 历史表，并提供启用/停用、回填、重新运行等受 `rbac.can('task.manage')` 控制的操作；`task-edit.tsx` 与 `task-wizard.tsx` 复用同一表单状态模型 `TaskFormState`，后者在向导中以四步（基本设置→分析数据→执行策略→确认并创建）引导新建流程。表单逻辑集中在 `components/tasks/task-form-sections.tsx`，导出 `BasicTaskFields` / `DataTaskFields` / `StrategyTaskFields` 三个纯 UI 子组件以及 `agentOf` / `assetOf` / `autoMapping` / `mappingIssues` 工具函数，实现 Agent Input Schema 与 Data Asset Field 之间的自动映射与校验。数据源采用双模式：默认走 `services/mock-service.ts`，当 `wfEnabled()` 为真时切换至 `services/wf-api`（bizApi.tasks、defApi.list/get）对接后端 workflows/resource API。依赖方向单向向下：pages → `@/components/tasks/*` → `@/components/ui/*`（shadcn）+ `@/hooks/*` + `@/services/*` + `@/mocks/data` + `@/domain/types`，不反向引用 pages。
