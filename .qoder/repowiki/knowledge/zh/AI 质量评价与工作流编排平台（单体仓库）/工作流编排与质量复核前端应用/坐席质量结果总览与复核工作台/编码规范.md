- 页面统一通过 `useListQuery` 管理 URL 查询参数，并使用 `parseListFilters`/`serializeListFilters` 在对象与 URL 字符串之间转换过滤条件。
- 数据获取采用 `useAsyncData(() => fetch(...), deps)` 模式，结合 loading/error/retry 状态渲染骨架屏或错误重试按钮。
- 筛选器采用受控组件模式：外部传入 `value` 与 `onChange`，内部维护本地 `draft` 状态，在“应用”时合并回父级过滤器。
- 多选/单选筛选统一使用 `Select` + `__all__` 表示清空，空值通过 `delete` 从 filters 对象中移除以保持 URL 简洁。
- 页面间跳转通过 `navigate('/quality/results?filters=...')` 携带序列化后的 filters，并在详情页用 `from` 查询参数恢复来源上下文以便前后导航。
- 列表与详情页通过 `wfEnabled()` 在 mock 与服务端 API 之间切换，保证开发期可离线联调、生产期接入真实工作流。
