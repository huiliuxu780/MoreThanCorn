模块以三个路由级页面为入口：`res-list.tsx` 通过 `domain`（ai/data）参数化渲染同一 `ResListPage`，使用 Tabs + FilterBar + Pagination 调用 `resApi.list(tab, {page, pageSize, search, status, health, type})` 分页；`res-detail.tsx` 基于 `type/id` 路由参数加载 ResourceDTO、usage 引用链与 toolVersions，并以 Overview/Config/Usage/Versions 四个 Tab 展示；`res-wizard.tsx` 实现四步向导（选择类型→填写配置→测试→完成），按 type 分支组装表单字段并先以 disabled 草稿保存再执行 `resApi.test`，通过后 toggle 启用。
可复用 UI 集中在 `src/components/resources/`：`resource-card.tsx` 定义 `TYPE_ICON`/`TYPE_LABEL`/`ResourceStatusBadge`/`MetaBadges`/`ResourceCard`，集中处理不同 resource type 的元信息徽章与操作菜单；`connection-picker.tsx` 封装 Connection 的选择与内嵌新建（Sheet），按协议动态渲染 endpoint/host/port/base_url 字段；`resource-dialogs.tsx` 提供 `ResourceTestDialog`（idle/running/ok/fail 四态）、`DeleteBlockedDialog`（引用阻断）与 `ConfirmDeleteDialog`（无引用二次确认）。
依赖方向单向向下：pages → components/resources → `@/services/resource-api`（及 `wf-api`/`conn-api`），不反向依赖业务逻辑；状态语义色通过 shadcn/ui 的 Badge variant 与 StatusTone token 管理，禁止硬编码 hex。
