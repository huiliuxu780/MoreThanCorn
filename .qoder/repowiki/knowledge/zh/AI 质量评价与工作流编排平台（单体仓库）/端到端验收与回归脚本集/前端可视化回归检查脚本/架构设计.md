模块包含两个独立的 ESM 脚本（check-history.mjs、check-minimap.mjs），均通过 puppeteer-core 启动本地 headless Chrome 访问 http://localhost:5173 下的 Agent 配置页面。
- check-history.mjs：固定打开特定 Agent 路由，点击“历史版本”按钮后通过 DOM 文本匹配校验是否包含 V2、线上、sha256 等关键字，截图至 /tmp/history-check.png 并以退出码 0/1 表达断言结果。
- check-minimap.mjs：接受 URL 参数（默认同 Agent 路由），监听 console error 与 pageerror 收集运行时错误，等待 networkidle2 后再测量 .react-flow__node 与 .react-flow__minimap-node 数量，要求两者相等且 minimap SVG 存在，截图至 /tmp/minimap-check.png 并据此设置进程退出码。
两个脚本均为一次性 CLI 工具，不依赖项目构建系统，直接以 Node 执行；依赖方向单向指向浏览器 DOM，不反向引用业务代码。
