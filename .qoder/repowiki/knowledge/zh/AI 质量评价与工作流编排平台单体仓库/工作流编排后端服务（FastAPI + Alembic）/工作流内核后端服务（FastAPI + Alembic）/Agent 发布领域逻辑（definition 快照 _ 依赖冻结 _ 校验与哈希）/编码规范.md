- 对外部资源引用统一以 `{type, ref, id?, version?, status}` 结构返回，status 枚举为 FROZEN/MISSING/DISABLED/UNPUBLISHED/NO_READY_VERSION，便于调用方汇总处理。
- 发布校验函数统一返回 `list[dict]` issues，每个 issue 包含 code/message/path 三段式字段，由调用方聚合展示。
- Agent 类型分支在多个入口函数（build_definition、freeze_dependencies、validate_publish）中通过 `if agent.type == 'autonomous'` 显式分流 autonomous 与 workflow-based 两条路径。
- 数据库查询优先尝试 `db.get(Model, ref)` 按 ID 查找，失败再回退到按 name 的 select 查询，以兼容 ID 与名称两种引用形式。
- definition 快照通过 `json.loads(json.dumps(...))` 深拷贝草稿图，确保发布后编辑草稿不影响已发布版本。
