仓库采用前后端同仓组织：frontend_app 通过 src/app.tsx 的固定路由表装配共享 UI（shadcn/ui sidebar-03）、domain/types.ts 领域类型、services/ 层与 pages/ 业务页面，形成质检/资源/任务/Agent/工具一体化前端；backend_service 以 FastAPI 聚合工作流编排、运行、资源、Agent 等子模块，统一暴露 /api/* REST 接口，并通过 agent_runtime.py + runner.py 驱动节点执行；docs_and_design 提供产品架构冻结基线与 UI/UX 原型，作为实现约束来源；scripts_and_e2e 使用 CDP 直接操控浏览器对 Agent 编辑器、后端 API 及数据链路进行端到端验证。前后端契约由 frontend/src/domain/types.ts 与 services/*.ts 定义，ListResponse<T>/ListParams 泛型分页贯穿列表查询，RBAC 鉴权中间件在路由层统一拦截。根目录 package.json 统一管理构建脚本（dev/build/typecheck/lint），vite.config.ts 配置 @ 路径别名指向 src，tsconfig.json 通过 project references 串联 app/node 两个 tsconfig，eslint.config.js 为全仓 TS/TSX 提供统一规则。
