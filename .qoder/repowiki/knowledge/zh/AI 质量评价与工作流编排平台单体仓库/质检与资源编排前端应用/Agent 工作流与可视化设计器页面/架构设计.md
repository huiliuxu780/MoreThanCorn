本模块由四个独立的路由页面组成，依赖方向单向：页面 → @/services/wf-api、@/services/resource-api → 后端 /api/agents、/api/workflows、/api/models、/api/model-providers 等 REST 端点。
- `wf-agents-list.tsx`：Agent 列表页，使用 `useListQuery(12)` + `pagedApi.agents` 分页加载，支持搜索、创建（POST `/api/agents`）与删除（DELETE），卡片点击跳转至编辑页；头像通过 `avatarFor` 按 id 哈希稳定取图。
- `wf-agent-editor.tsx`：按 `agent.type` 分发三种编辑器——`dialogue`/`expert-group` 复用 `WfDesignerPage` 并传入 agent 元信息；`autonomous` 提供角色提示词、模型选择、技能/插件/工作流/知识多选器与右侧预览调试面板（基于 `streamRunEvents` SSE 流式渲染），并支持双列模型对比；保存时携带 `configRevision` 实现乐观并发控制（409 冲突回退）；内置 `RegistryPicker` 组件统一封装注册表多选绑定，杜绝自由文本假引用。
- `wf-designer.tsx`：核心画布页面，基于 `@xyflow/react` 渲染节点图，内置节点卡（`WfNodeCard`）、变量级联选择器（`VarCascader`，仅展示可达祖先输出）、按节点类型分发的配置抽屉（`ConfigDrawer`）、调试输入（`DebugDrawer`）、运行观测（`RunsDrawer`，3s 轮询）、定时任务（`ScheduleDrawer`）、版本发布与历史、评估与进化面板；颜色与图标集中定义在顶部常量 `C` 与 `TYPE_ICON` 映射中；无专项表单的节点通过 `GenericSchemaForm` 按注册表 schema 通用渲染。
- 页面之间仅通过路由参数传递 `workflowId`/`agentId`，无共享状态。
