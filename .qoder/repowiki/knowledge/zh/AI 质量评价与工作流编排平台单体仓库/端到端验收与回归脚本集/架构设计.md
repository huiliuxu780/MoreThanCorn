本模块为纯脚本集合，按用途分为两类：Python 侧 `cdplib.py` 基于 `websockets` 封装 CDP Tab/Network/Runtime/Page 能力；Node.js `.mjs` 脚本自实现 CDP 通信层（通过 `fetch('/json/new'|'/json/list')` 获取 `webSocketDebuggerUrl`，用 `pending Map` 绑定请求 id 与回调），所有脚本均连接本地 `http://127.0.0.1:9222` 的 Chrome 调试端口再驱动 `localhost:5173` 前端。用例分层覆盖：`e2e-replica.mjs`/`e2e-replica2.mjs` 针对 UI 复刻规范断言；`e2e-p0.mjs` 覆盖 create→add node→connect→configure→autosave→reload→checklist 主流程；`e2e-acceptance.mjs` 做最小 acceptance 检查；`check-history.mjs`/`check-minimap.mjs` 聚焦历史版本抽屉与小地图缩略渲染；`verify-fullstack.mjs` 不依赖浏览器，直接调用后端 `http://127.0.0.1:8100` 的 REST API，按 S1–S14 阶段串联 Connection/Datasource/Data Asset/Data Definition/AI Resources/Workflow Run/Rule Engine/Review/Task/Batch/Schedule/Delete-protection/Evaluation/Agent run/version pinning 等场景。依赖方向单向：脚本 → CDP/HTTP → 前端或后端服务，模块之间无相互引用。
