- 每个脚本独立 launch 一个 headless Chromium 实例并在末尾 close()，不跨脚本共享浏览器进程。
- 登录流程统一通过检测 input[placeholder="用户名"] 判断对话框存在，再 type 用户名/密码并点击文本为“登录”的按钮。
- UI 元素定位优先使用基于可见文本的 querySelectorAll("button") 过滤（如“立即执行”“进入复核”“完成复核”“通过/维持”），而非固定 class/id。
- 关键步骤前后均调用 page.screenshot 写入 /tmp/accept-evidence/ 下的编号 PNG 作为验收证据。
- 异步等待采用 setTimeout + waitUntil:"networkidle2" 的组合，避免使用精确时间片或隐式等待。
- 错误收集通过 page.on("console", ...) 与 page.on("pageerror", ...) 捕获控制台错误并截断前 150 字符打印。
