模块由四个文件构成单向启动链：`src/main.tsx` 作为 Vite 默认入口，使用 `react-dom/client` 的 `createRoot` 在 `#root` DOM 节点上渲染，自外向内依次包裹 `StrictMode` → `BrowserRouter` → `@/components/ui/tooltip` 的 `TooltipProvider` → `<App />`，并在此处引入全局样式与 `@xyflow/react` 图表样式；`src/app.tsx` 通过 `React.lazy` + 顶层 `Suspense`（fallback 为 `TableSkeleton`）对 `@/pages/*` 下的所有页面进行按需加载，并以 `Routes` + `element={<AppShell />}` 嵌套的方式集中声明路由表，按业务域划分为智能质检（`/quality/*`）、配置管理（`/config/tasks|agents|workflows|ai-resources|data-resources|data-assets|result-rules`）、系统设置（`/settings/*`），并通过 `Navigate` 将旧 `/config/tools*` 收敛至 `/config/ai-resources`；`src/index.css` 基于 Tailwind v4 的 `@import "tailwindcss"` 引入，定义 oklch 色板变量并在 `:root` / `.dark` 双主题下映射到 shadcn 语义 token（background/foreground/card/primary/secondary/muted/accent/destructive/sidebar/chart-*），通过 `@theme inline` 暴露为 CSS 变量供组件消费；`src/vite-env.d.ts` 仅引用 `vite/client` 启用 Vite 内置类型增强。依赖方向严格单向：main → app → components/pages/services，不反向引用业务逻辑。
