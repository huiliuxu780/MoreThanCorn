- 所有 HTTP 请求通过 `@/services/wf-api` 暴露的 `pagedApi`/`agentApi`/`wfApi`/`resApi` 调用，避免在页面内硬编码 URL 路径。
- 分页列表统一使用 `useListQuery(defaultPageSize)` 获取 `params`/`update`，并通过 `Pagination` 组件驱动 page/pageSize/search 变更。
- 保存操作携带 `revision`/`configRevision` 字段实现乐观锁，捕获以 `409` 开头的错误后拉取最新数据并提示用户刷新。
- 资源绑定一律通过注册表接口（`resApi.registry('tool'|'knowledge'|'model'|'mcp'`）加载候选项并以 id 存储，禁止自由文本引用。
- 视觉样式集中在文件顶部常量对象（如 `C`、`INK2`、`INK3`、`CARD`）中声明，禁止在 JSX 中散落硬编码 hex 色值。
- 侧边抽屉（配置/调试/运行观测/定时任务）采用绝对定位 + 固定宽度 + `border-l` 的右滑面板模式，统一使用 X 关闭按钮与 `cardBorder` 边框色。
