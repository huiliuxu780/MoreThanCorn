server/app/main.py 作为唯一进程入口：lifespan 中初始化数据库连接、加载 app/models.py 的 ORM 模型并启动 runner.start_worker 后台调度器；挂载 CORS 与基于 WF_API_TOKEN 的 RBAC 中间件后，集中 include_router 注册 workflows/registry/runs/business/resources/admin/agents 七个路由模块。共享核心层提供 FastAPI 应用主体与 Alembic 迁移，将 SQLAlchemy Base.metadata 暴露给各业务路由复用；workflows_routers 子模块实现 HTTP 接口层，tests 子模块通过 FastAPI TestClient 直接复用该 app 实例进行端到端验证。agent_runtime.py 负责节点执行，runner.py 负责 worker 调度，二者共同实现通用 AgentNodeKind（input/llm/tool/transform/condition/router/human-interrupt/create-record/notification/end）的执行语义，并通过 app/db.py 的 SessionLocal 与 models.py 的 ORM 实体访问同一份 Postgres 数据。
