- 每个路由文件定义一个 `APIRouter(prefix=..., tags=[...])` 并按资源维度拆分（workflows/registry/runs）。
- 数据库会话统一通过 `Depends(get_db)` 注入，并在需要时显式 `from ..models import ...` 延迟导入以避免循环依赖。
- 业务对象不存在时统一抛出 `HTTPException(404, 'xxx not found')`，并发冲突使用 409（如草稿版本冲突、校验失败）。
- 时间字段统一通过 `.isoformat()` 序列化为 ISO 8601 字符串，新记录使用 `datetime.now(timezone.utc)` 写入。
- 发布类操作先对 `draft_definition` 执行 `WorkflowDefinition.model_validate` 再进入持久化，保证 schema 一致性。
- 对外响应采用内联 dict/Pydantic model 组合而非独立 DTO 类，保持路由层轻量。
