仓库采用前后端同仓组织：frontend_app 的 src/domain/types.ts 定义 QualityResult、EvaluationAgent、Tool、DataAsset、AnalysisTask、Run、InteractionExecution、ResultRuleSet 等核心实体，backend_service 的 server/app/models.py 作为 ORM 映射同一份模型，形成单一事实源；运行时由 backend_service 的 agent_runtime.py + runner.py 驱动节点执行，scripts_and_e2e 使用 CDP 操控真实浏览器对 Agent 编辑器、后端 API 及数据链路进行端到端验证，docs_and_design 提供产品架构冻结基线与 UI/UX 原型作为实现约束来源。根目录 package.json 统一管理构建脚本（dev/build/typecheck/lint），vite.config.ts 配置 @ 路径别名指向 src，tsconfig.json 通过 project references 串联 app/node 两个 tsconfig，eslint.config.js 为全仓 TS/TSX 提供统一规则。
