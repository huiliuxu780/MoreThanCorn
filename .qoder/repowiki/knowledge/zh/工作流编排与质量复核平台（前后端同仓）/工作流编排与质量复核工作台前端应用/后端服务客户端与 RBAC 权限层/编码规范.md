- 所有列表查询统一接收 `ListParams`（search/page/pageSize/sort/filters/tab），内部先 `parseListFilters` 解析 filters，再链式 filter 叠加条件，最后返回 `ListResponse<T>` 或 `Paged<T>`。
- 真实 API 客户端统一通过内部 `req<T>(path, init?)` 封装 fetch，自动附加 Content-Type 与 Authorization: Bearer 头，并在非 2xx 时抛出带 status/detail 的 Error。
- 每个导出 API 对象（`wfApi`、`agentApi`、`resApi`、`defApi`、`connApi`、`bizApi`、`evalApi`、`lockApi`、`governanceApi`）按领域分组聚合 CRUD 方法，调用方无需感知底层 URL 拼接。
- 后端响应在业务适配层集中映射为 domain 类型（如 `RUN_STATUS`/`EX_STATUS`/`REVIEW_MAP` 字典转换），避免组件直接处理后端枚举差异。
- SSE 事件流通过 `streamRunEvents` 统一实现：fetch + ReadableStream 逐块解析 `data:` 行，遇到终止事件后自动结束，并支持 Last-Event-ID 断线续传。
- RBAC 权限通过 `permsFor(role)` 构建 `Set<Permission>` 进行 O(1) 判定，`actionVisibility` 同时考虑权限与对象状态，返回 `hidden/enabled/disabled` 三态。
