# E2E 验收用例（SDD D-5 交付物）

自动化门禁（每次提交必跑）：
1. `cd server && .venv/bin/python -m pytest tests -q` —— 全绿（当前 85 条）。
2. `npm run build` —— 构建通过。
3. `node scripts/verify-fullstack.mjs` —— 全链路 PASS（含版本语义场景）。
4. `node scripts/check-minimap.mjs` —— 小地图节点缩略数 = 画布节点数。
5. `node scripts/check-history.mjs` —— Agent 历史版本抽屉显示版本/环境徽标/artifactHash。

## 手工验收动线（逐项对照调研 §15）

## A. 配置闭环（§15.1）
- [ ] 创建三类 Agent；名称超 20 字被拒（400 NAME_TOO_LONG）。
- [ ] 两个标签同时编辑同一 Agent：后保存者收到 409 REVISION_CONFLICT。
- [ ] 刷新页面配置不丢（名称/描述/挂载/记忆/对话体验）。

## B. 发布闭环（§15.5）
- [ ] 发布对话框：生成版本 → 沙箱/线上部署；版本抽屉显示环境徽标 + artifactHash。
- [ ] 发布校验拦截：空 Prompt 的自主规划发布被拦（409 + issues）。
- [ ] 回滚：把旧版本重新部署，环境徽标回到旧版本，历史版本不变。
- [ ] 审计日志页（/settings/audit，Admin 角色）可见发布/部署/删除记录。

## C. 运行闭环（§15.2–15.4）
- [ ] 自主规划：流式出字 + 步骤折叠 + 续问气泡；模型对比双栏；语音播报。
- [ ] 对话编排：`开始→大模型→条件→结束` 全链运行；end 输出引用上游变量；连线可删除；节点单测。
- [ ] 专家组：Agent选择→Agent执行 真路由（主要/兜底）；成员池与节点联动。
- [ ] 运行版本语义：发布后改草稿，指定旧版本运行仍复现旧行为；定时任务无发布版本被拦。

## D. 治理（调研 13）
- [ ] 角色切换器：Viewer 无发布/删除按钮；Publisher 可发布；Admin 可见审计与强解锁。
- [ ] 连接编辑：Secret 留空保留原密钥；填写=轮换。
