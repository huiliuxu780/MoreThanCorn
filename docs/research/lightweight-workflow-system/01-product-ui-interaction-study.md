# 01 · 目标产品 UI / 交互研究（Observed-UI）

> 产品：瓴羊 quickService 配置中心 · Agent（新版）。2026-08-21 真实账号实操。
> 详细版：`docs/research/product-ui-interaction-study/`（4 文档+24 截图）；截图副本在 `evidence/screenshots/`。
> 本文提取对轻量 Workflow 系统设计直接有用的事实与结论。

## 1. 编辑器骨架（01/03 截图）

- 全屏沉浸式：顶栏 + 画布 + 右抽屉；无二级导航。
- 顶栏：`返回 | 图标+名称+状态标签(待发布) | 自动保存于 <t>` … `检查(红点) | 历史版本 | 保存 | 发布(黑主)`。
- 画布：React Flow；点状网格；minimap；底部悬浮条 `+添加节点 | 适应 | 布局 | 缩放% | 试运行(蓝主)`。
- 右抽屉≈335px：头部(图标+可编辑名称+…+×) → 说明文案 → 折叠分区。

## 2. 节点与配置（02/03/09/10/11 截图）

- 添加节点：popover 两组 14 项（信息处理 12 / 代码编辑 2），**无搜索**。
- 节点卡=配置摘要：输入/输出/模型/提示词/选项行 + 类型 chip（Str./Int./Obj.）+ 灰色"未配置"。
- 大模型：单次/批处理 Tab；模型下拉(13 项,能力标签,check)；输入变量表(+添加; 值=输入或引用+⚙级联; −删除)；提示词富文本("#"唤起变量)；输出格式(Markdown)+固定输出表+输出示例。
- 开始：9 系统变量表(名/类型/必填/描述)+添加。结束：输出变量表。
- 插件工具：建节点时绑定具体插件（来源:插件市场/插件名称）；输出 schema 树；流式输出 switch；授权以 Authorization 类输入变量注入。
- 问题分类：必填 *query；分类行(拖拽+名称 0/20+描述+删除)+其他分类；校验 alert。
- 代码编写：内嵌深色 IDE（args/ret 约定）+外开编辑器按钮；输出表自定义。
- 选中节点：蓝环 + ▶单节点运行 + …菜单。

## 3. 校验/运行/发布状态机（12/15/16/17 截图）

```
试运行 --有未配置/未连接--> 红toast"请先配置节点"（硬阻断）
检查红点=问题数 --> popover 清单(节点未连接完整|节点未完整配置)
发布 --未试运行--> 软警告模态(试运行|继续发布|取消)
历史版本抽屉：未发布=空态
保存：自动保存时间戳 + 手动保存并存
```

## 4. 列表/工具/日志/设置（18–22 截图）

- 工作流列表：卡片网格；搜索/筛选/排序/管理标签/+创建(黑)；卡=状态#未发布+更新时间+来源标签。
- 工具页：Tab 工具插件/MCP插件；调用日志(新标签)/管理标签/+创建插件。
- 插件调用日志页：搜索工具编码+归属插件/调用应用筛选+时间范围(默认15min)+表(名称/编码/状态/耗时ms/归属/调用应用/请求时间/操作)。
- 系统设置→应用及插件→插件管理：平台插件卡(设置/停用)，已启用/已停用分区。
- **无 Schedule 入口**；触发=对话/API/子工作流（开始节点说明）。
- **无工作流 Run 历史入口**（仅工具调用日志）。

## 5. 第二轮补采：Agent 层与全局资源（Observed-UI）

### 5.1 产品层级（修正）

```
Agent（三形态：自主规划 / 对话编排 / 编排Agent专家组）
 ├─ 内嵌 Workflow（画布即 flow 编辑器；保存 source='agent-default'；可再引用资源级 subflow）
 ├─ Agent 配置信息：基本信息/对话体验(自动续问/闲聊兜底)/高级设置
 ├─ 知识兜底：知识库 + 专业词库 + 问答经验库
 ├─ 记忆：customVariableMemory + 工作流内"记忆变量"节点读写
 └─ 引用全局资源：知识库 / 技能 / 工作流 / 工具 / 标签
资源级 Workflow（第一轮所采对象）= 可被 Agent 与父 Workflow 复用的 subflow
```
证据：创建 Agent 弹窗三型卡片（含流程示意插画）；点型卡**直接建草稿并跳 QuickExperience**（无命名步骤，自动名 `对话编排agent_<rand><ts>`）；`save_agent_config.config.workflows[{workflowCode}]` 以 code 引用内嵌流；palette 四组含 `Agent/信息收集/对话回复/记忆变量` 等 subflow 没有的节点。

### 5.2 三型编辑器形态

| 形态 | 编辑器形态（Observed） |
|---|---|
| 对话编排 | flow 画布（Start 含公共参数+`reference`）+ 右栏 Agent 配置信息；顶栏 **V1.0.1 版本号+灰度**、Tabs=Agent搭建/运行观测/效果评测/进化；保存/发布 |
| 自主规划 | **无画布**：模型选择 + 角色能力描述（Markdown 模板 #角色/##目标/##技能/##限制，"AI生成"按钮+选模板）+ 挂载 技能/插件/工作流/知识/记忆变量 + 右栏**预览调试（添加对比模型 1/2，双模型并排对比）** |
| 编排Agent专家组 | 创建卡插画=条件路由到多 Agent 节点；编辑器内部本轮未进入（列表卡横滚+只读入口未打通），**Unverified**，同壳层家族推断 |

### 5.3 运行观测 Tab（Observed）

`当前版本 V1.0.1 | 灰度(-) | 消耗量 -/-` + 子 Tab **观测配置 / 观测回放 / 智能洞察**（"当前运行正常，暂无异常洞察"）——生产级 Agent 可观测性内建于编辑器。

### 5.4 全局资源页（Observed）

- 知识库：知识管理/个人空间；添加知识；目录树；筛选(类型/生效状态/学习状态/标签)；**命中测试**；批处理；卡片/列表切换；条目带学习状态(学习失败/重新学习)。
- 技能：导入/创建技能；技能=可挂载能力卡（例"知识库检索工具"：语义/关键词/混合检索），状态 草稿待发布。**知识检索以技能形态存在**（与"工具"并列）。
- 标签管理：导入/添加标签；表(名称/类型/分组/负责人/描述/操作)。
- 工具/工作流：第一轮已采（pluginBase / newWorkFlow）。

## 5b. 第三轮深跑：三型"编辑+填充+运行"（Observed-UI）

| 型 | 编辑/填充实操 | 运行结果 |
|---|---|---|
| 对话编排 | 新建 TEST agent→内嵌流加 大模型+条件判断 节点、拖线（含"不能重复连线"反馈）、LLM 配模型+提示词、条件构建器=引用变量⚙+条件关系+比较变量、End 输出值 | ✅ chat 运行 SSE：开始执行完成→大模型执行完成→结束执行完成 |
| 专家组 | 新建空 agent；列表/卡片/发布态"立即体验"模态（QR+线上访问） | ✅ chat 运行 SSE：开始→结束执行完成 |
| 自主规划 | 角色能力描述模板+AI生成+挂载技能/插件/工作流/知识/记忆+预览调试(对比模型1/2) | ⚠️ 体验页登录墙未跑通（协议同 chat SSE，Inferred） |

运行态 UI 观察：对话运行在 SSE 推送时以 title 序列渲染节点执行进度；工作流试运行走调试配置面板（Start 参数表单+开始运行）。

## 6. 借鉴决策（供 04/06 使用）

借鉴：检查清单红点；节点卡摘要+类型 chip；自动保存时间戳；发布软警告三选项；统一变量引用(⚙级联+"#")；右抽屉 schema 驱动配置；日志页筛选+时间窗+耗时列。
不照搬：无搜索节点面板；客服域节点/插件体系；iframe 子应用；水印；纯卡片列表（规模后需表格切换）。
缺口（我们需自补，quickservice 没有或弱）：Run 列表与节点级日志、运行中画布状态、版本回滚、Schedule、MCP 之外的 Tool 测试入口。
