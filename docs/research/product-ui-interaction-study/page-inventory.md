## 2. 导航行为观察

- 一级=图标栏（跨工作台），二级=工作台内左导航；编辑器为**全屏沉浸式**（隐藏二级导航，仅顶栏+返回）。
- 面包屑：无；靠返回箭头 + 顶栏 Tab 定位。
- 全局搜索：无（仅页内搜索：工作流名称、插件名称、配置项、工具编码）。
- 用户/空间切换：头像在右上，未展开验证；"切换工作台"九宫格在图标栏底部。
- 新建入口：列表页右上黑色主按钮（创建工作流/创建插件），突出度足够。
- 页面间跳转：列表↔编辑器为同标签路由切换；**调用日志为新标签打开**（保留编辑上下文，好）。
- 浏览器返回：编辑器→列表 正常（自测返回箭头等效）。
- 刷新后状态：编辑器自动保存，刷新不丢草稿（由"自动保存于"推断+自动保存机制证实；未做刷新实验）。
- URL 反映对象：是（processId）；不反映编辑器内部状态（选中节点/抽屉）。

## 3. 列表页体验（工作流列表）

- Header：无独立页标题（导航项即标题），工具条直接承担页头职能。
- 主按钮：+创建工作流（黑底白字，右上）。
- 搜索：左置，placeholder"搜索工作流名称"。
- 筛选：单个"全部"下拉（推测=标签或状态）；排序"降序"下拉；无已选回显。
- 展示：卡片网格（≈4 列@1680px），非表格。
- 状态标签：`# 未发布`（灰）；卡片右上来源标签"自主创建"。
- 行操作：未观察到 hover 操作菜单（**未验证**，hover 取证失败）。
- 批量操作：无。空状态：未触发（有 1 条数据）。
- 创建/复制/删除/归档入口：仅创建可见；复制/删除疑似在编辑器内或 hover 菜单（未验证）。
