# 交互规格（可直接转开发 Spec 的部分）

> 来源：screenshots/ 对应截图 + DOM 快照。标注 [验证]=实操确认；[推断]；[未验证]。

## S1 编辑器骨架

- 顶栏 44px：`[返回] [应用图标][名称][状态标签:待发布] / 自动保存于 <M/D/YYYY, h:mm:ss AM>` … `[检查(红点=问题数)] [历史版本] [保存(次按钮)] [发布(主按钮·黑)]`。[验证]
- 画布：React Flow；点状网格；minimap 底部居中；悬浮工具条底部居中：`[+添加节点] [适应画布] [自动布局] [?] [100%▾] [＋] [?] [试运行(主·蓝)]`。[验证]
- 配置抽屉：右侧全高，宽≈335–390px，白底左阴影；打开不遮挡顶栏。[验证]

## S2 节点卡片（画布）

- 结构：`[彩色圆角图标][标题][折叠chevron]` + 行：`标签(输入/输出/模型/提示词/选项/来源/插件名称) + 值`。
- 值样式：变量名 + 类型 chip（Str./Int./Obj.，浅灰底小字）；未配置=灰色"未配置"。
- 选中：蓝色描边环；右上浮现 `[▶单节点运行] […菜单]`；右侧端口高亮"+"态。[验证]
- 端口：左入右出，蓝色 4–6px 圆点；连线贝塞尔。[验证]
- 节点宽≈250–300px，圆角≈8px，轻阴影。[视觉估计]

## S3 添加节点菜单

- 触发：点击底部"+添加节点"；popover 锚定按钮上方。[验证]
- 分组与项（实测）：
  - 信息处理：大模型、工作流选择、工作流执行、插件工具、客服工具、问题分类、Query改写、知识检索、数据查询、条件判断、工作流、图像生成
  - 代码编辑：代码编写、变量处理
- 项=图标+文字，hover 浅底；点击即在画布加入该节点（放置位置规则**未验证**）。
- 无搜索/无最近使用。[验证]

## S4 配置抽屉通用模式

- 头部：`[图标][名称textbox可编辑] […][×]`；下一行灰色说明文案（每节点一句，文案见报告 §4.4）。[验证]
- 分区：标题+chevron 折叠；默认展开。[验证]
- 变量表组件（输入/输出通用）：
  - 列：变量名 | 类型 | 变量值 | (删除)；开始节点列：变量名|类型|必填|变量描述|(删除)。
  - 空态：信封插画 + "No data"。
  - `+ 添加` 链接（加号图标+蓝字）新增行。
  - 行内：名称 textbox（placeholder"自定义变量名称"）；类型 combobox（默认 Str.）；值 textbox（placeholder"请输入或引用变量值"）+ `[⚙]` 引用按钮 + `[−]` 删除。
  - 引用菜单：`[⚙图标] 系统变量 >` 级联（子级**未验证**）。
  - 必填标记：`*query` 红星前缀（问题分类）。[验证]
- 校验：分类名称空 → 行内 alert"请输入分类名称"；名称计数 `0 / 20`。[验证]

## S5 大模型节点 Spec

- Tab：单次 | 批处理（segmented，白底选中）。[验证]
- 模型 select：扁平列表 13 项；每项=名称+能力标签（文本生成/深度思考）；选中项右侧 check。[验证]
- 提示词：富文本区，placeholder"请输入提示词"；helper"输入 "#" 唤起变量选择器，支持插入变量"。[验证]
- 输出：`输出格式: [Markdown▾]` + 说明文案；固定输出表（output/thought/answer，String，含描述）；`[输出示例]` 次按钮 + helper"用于定义预期输出结果的数据示例，帮助大模型更准确的输出Json参数"。[验证]

## S6 校验/运行/发布状态机

```
[编辑] --自动保存--> 草稿(待发布)
[试运行] --存在 未配置/未连接 节点--> 红toast"请先配置节点"（阻断）
[检查icon] 红点数 = 问题数；popover 列表：节点图标 + "节点未连接完整|节点未完整配置"
[发布] --未试运行--> 模态"发布前未试运行"（试运行 / 继续发布 / 取消）
[发布成功]--> 历史版本抽屉出现版本（空态"暂无历史版本"）[推断]
```
[验证] 至模态与空态；[推断] 发布后版本生成。

## S7 工具页与日志

- Tab：工具插件 | MCP插件（下划线式）。[验证]
- 按钮：调用日志（新标签）/ 管理标签 / +创建插件（黑主）。[验证]
- 卡片：图标+名称+描述+`# 状态`+更新时间+来源标签。[验证]
- 日志页：`[←][标题:工具插件调用日志]`；搜索工具编码；combobox 全部归属插件/全部调用应用；时间范围（开始/结束，默认≈最近15分钟，带 calendar/清除/刷新图标）；表：工具名称|工具编码|状态(带筛选)|耗时(ms)|归属插件|调用应用|请求时间|操作；空态"暂无数据"。[验证]

## S8 插件工具节点绑定模式（关键结论）

- 采用"**通用插件工具节点 + 建节点时绑定具体工具**"：节点卡显示 来源:插件市场 / 插件名称:<插件>；输入 schema 含授权变量（如 `X-bizphin-authorization-recordId`、`Authorization`）→ 连接/授权以"授权变量"形式注入输入表。[验证]
- 输出以 **schema 树**展示（可嵌套 Object）。[验证]
- 附加开关：流式输出（switch，默认开，带警示图标说明）。[验证]

## S9 空/加载/错误文案集（可直接复用模式）

- 表格空：No data / 暂无数据；列表空：暂无插件；版本空：暂无历史版本；加载：骨架屏+双点 spinner；错误 toast：红框"请先配置节点"；警告模态：橙叹号+建议文案。[验证]
