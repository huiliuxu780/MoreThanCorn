# 设计系统观察（视觉估计，未取精确 CSS 值）

> 方法：1680×1000 视口截图目测；标注 *估计*。

## 1. 布局骨架

| 区域 | 尺寸* |
|---|---|
| 全局图标栏 | 宽≈57px，蓝色（#2E6BE6→#3D7FFF 渐变感），图标白色 20–22px，选中项白底圆角块 |
| 二级导航 | 宽≈225px，白底；组标题"场景/资源"12px 灰；项 14px，图标 16px；选中=浅蓝底(#EAF1FF*)+蓝字 |
| 顶栏 | 高≈44–48px，白底，底部 1px 浅边框 |
| 编辑器顶栏 | 同上；标题 15–16px medium；状态标签=橙底浅橙字小圆角 |
| 配置抽屉 | 宽≈335–390px，全高，左缘阴影 |
| 内容留白 | 页边距≈24px；卡片间距≈16–20px；抽屉内分区间距≈20px |

## 2. 颜色

| 用途 | 值* |
|---|---|
| 主色（链接/选中/试运行/端口） | #3D6BFF–#4472FF 蓝 |
| 主按钮（发布/创建） | 近黑 #17181A，白字，圆角≈6px |
| 次按钮 | 白底+1px 灰边 |
| 画布背景 | #EEF1F6*，点状网格点 #D8DCE6* |
| 页面背景 | #F5F6FA* |
| 卡片/抽屉/顶栏 | #FFFFFF |
| 节点图标色 | 橙(#F97E2B*)=模型/逻辑类；蓝(#3D6BFF*)=开始/结束/检索；紫(#7B61FF*)=代码/变量 |
| 状态橙（待发布标签） | 浅橙底+橙字 |
| 错误红 | #F56C6C*（toast 边、检查清单文字） |

| 类型 chip | 底 #EEF1F6*，字 #7A8699*，11px |

## 3. 字体与层级*

- 基准 14px；导航 14；组标题/辅助 12；节点标题 13–14 medium(500)；抽屉标题 15–16(600)；变量名 12–13；chip 11。
- 字重整体偏轻：400 为主，标题 500/600，无 700 大黑体。

## 4. 圆角 / 阴影 / 边框*

- 卡片 8–12px；按钮 6px；chip 4px；弹窗 8–12px；抽屉 0（贴边）。
- 阴影极轻：`0 2px 8px rgba(31,35,41,.06)` 感；节点选中=2px 蓝环+轻阴影。
- 边框 1px #E5E8EF*，用于输入框/次按钮/表格线（表格用浅横线，无竖线）。

## 5. 组件风格

- 按钮三级：黑主 / 白次 / 蓝文字链接（+添加）。
- 输入框：浅灰底(#F5F6FA*)或白底+浅边，圆角 6，高 28–32。
- 下拉：白底+浅边+右侧 chevron；弹层白圆角+轻阴影；模型项带能力标签 chip。
- 表格：无外框，表头 12px 灰，行高≈40，空态居中插画+灰字。
- 弹窗：居中，宽≈330–480，遮罩≈45% 黑；警告=橙圆叹号。
- Toast：顶部居中，红边浅红底小条（错误）。
- 抽屉：右出，全高。
- 开关：Ant 风格 switch（流式输出）。
- 分段器：白底槽+选中白块（单次/批处理）。
- 空态插画：线性浅色小插画（信封/灯泡/打印机）。
- 代码编辑器：深色主题（#1E222A* 底，语法高亮橙/蓝/灰），行号左列。

## 6. Workflow 节点视觉规范*

- 卡片 250–300×自适应；白底；圆角 8；阴影轻；内边距 12–14。
- 头部：24px 彩色圆角图标 + 13–14px 标题 + chevron。
- 行：标签 12px 灰 + 值 12–13px；类型 chip 紧随变量名。
- 端口：6px 蓝圆，悬停/可连时"+"放大态。
- 选中：2px #3D6BFF 环；浮现 24px 圆形▶与…按钮。
- 连线：1.5px #A8B3C5* 贝塞尔，端点蓝圆。

## 7. 值得我们沿用的视觉决策

1. 黑主按钮 + 蓝功能按钮的双主色克制用法（黑=对象级创建/发布，蓝=运行/链接）。
2. 节点类型用图标底色族（蓝=边界节点、橙=智能/逻辑、紫=代码/数据）——一眼分类。
3. "未配置"灰字 + 类型 chip 的摘要语法，让画布自带完整度信息。
4. 极轻阴影 + 1px 浅边的"纸面"质感，适合信息密集配置类产品。
5. 空态统一插画+四字文案（暂无数据/暂无插件），成本低、一致性强。
