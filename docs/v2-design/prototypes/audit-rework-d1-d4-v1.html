D4 · 双「数据源」边界说明 + 术语表（推荐案：不动导航）

审计问题：「数据接入」与资源域「Datasources/Data Assets」概念易混、中英术语无统一原则。 提案：两页互设一句边界说明+跳转；ui-terms.ts 扩 glossary 作为文案单一事实源。

ℹ︎ 这里管理事件入口（Webhook/轮询：外部系统把事件推给平台，触发自动任务或分析批次）。 要找数据库/对象存储等数据资产连接？前往 能力与资源 → 数据资产 →

② 资源页 · 数据资产 tab 说明条

ℹ︎ 这里管理数据资产（PostgreSQL 等数据库连接与表，供分析任务读取/写回）。 Webhook/轮询等事件入口在数据接入 →管理。
