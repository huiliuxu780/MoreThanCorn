危险操作需要确认
开启后，Agent 检测到高风险命令会先暂停执行，并向你请求确认（对话页出现批准/拒绝卡）。关闭时「命令守卫」tab 整页只读灰化，但严重级规则仍 bypass-immune 转直接阻止。
⚠ 当前不会检查危险操作，Agent 将按其他已有权限继续执行。严重级规则在 bypass 下自动转为「直接阻止」（官方 bypass-immune 语义），不会被静默放行。

Shell 逃逸检测平台固定安全层 · 7 子规则 · 不可关闭
检测 Shell 命令中的引号/反斜杠/换行/注释等易被规避过滤的混淆写法；命中即走审批流程。
  • 命令替换 原生：反引号、$()、<()、=()、$[]、Zsh =cmd（官方解析器 bypass-immune ASK）
  • 混淆标志 规划 P2：$'…'、$"…"、''-、""- 等特殊引用
  • 反斜杠转义空白 规划 P2：引号外 \ 空格/TAB 拆 token
  • 反斜杠转义操作符 规划 P2：引号外 \; \| \& 等（find -exec 豁免）
  • 换行符 规划 P2：引号外 \r/换行隐藏第二条命令（heredoc 豁免）
  • 注释引号失同步 规划 P2：# 注释内出现单/双引号
  • 引号内换行 规划 P2：引号内换行且下行以 # 起始
诚实标注：仅「命令替换」为官方解析器原生执行（bypass-immune）；其余 6 子规则为平台解析器扩展（P2），扩展前标「规划」不假装生效。本层不提供关闭开关（关掉＝拆安全网）。
